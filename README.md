# Carte de Visite Digitale Interactive - Youmah Saoudatou Traore

Carte de visite digitale moderne style Linktree / vCard hébergée gratuitement sur GitHub Pages.

## 🚀 Fonctionnalités
- **Enregistrement en 1 clic** : Fichier `contact.vcf` (vCard 3.0) préconfiguré (téléphone, WhatsApp, email, réseaux sociaux).
- **Contact direct** : Boutons d'action rapide vers WhatsApp, appel direct et e-mail.
- **Réseaux sociaux** : Liens directs vers TikTok et Snapchat.
- **Partage natif** : Intégration de l'API Web Share et copie du lien avec notification toast.
- **Design moderne Dark Mode** : Palette Slate `#0f172a`, responsive mobile first, zéro dépendance externe.
- **Optimisation SEO & Open Graph** : Aperçu riche automatique lors des partages sur WhatsApp, Snapchat, SMS, etc.
